# موقع Lucine Studio

موقع تعريفي بثلاث لغات (عربي / فرنسي / إنجليزي) لعلامة **Lucine Studio**، مع نموذج لاستقبال طلبات الأطباء عبر واتساب، ولوحة تحكم لإدارة محتوى الموقع وروابط التواصل الاجتماعي.

## هيكل الملفات

```
lucine-site/
├── index.html        الموقع العام
├── admin.html         لوحة التحكم
├── css/style.css       تصميم الموقع
├── css/admin.css       تصميم لوحة التحكم
├── js/config.js        الإعدادات والمحتوى القابل للتعديل
├── js/i18n.js         نصوص الواجهة الثابتة (أزرار، تسميات الحقول...)
├── js/main.js         منطق الموقع العام (اللغات، النموذج)
├── js/admin.js         منطق لوحة التحكم
└── assets/logo.png     شعار البراند
```

## كيف يعمل نموذج الأطباء

بما أن الموقع "ستاتيكي" (بدون خادم/سيرفر خلفي)، لا توجد طريقة مجانية لإرسال رسالة واتساب تلقائيًا دون تدخل الزائر. الحل المعتمد هنا هو الأسلوب القياسي على هذا النوع من المواقع:

1. الطبيب يملأ الفورم ويضغط "إرسال الطلب عبر واتساب".
2. يفتح المتصفح تلقائيًا محادثة واتساب مع رقمكم، **ورسالة جاهزة معبأة مسبقًا** بكل معلومات الطبيب.
3. يكفي أن يضغط الطبيب على زر الإرسال داخل واتساب لإتمام العملية، ومن هناك تبدأ محادثتكم معه.

هذا لا يحتاج أي اشتراك أو تكلفة إضافية. لو رغبتم مستقبلًا بإرسال تلقائي 100% بدون تدخل الزائر، فهذا يتطلب WhatsApp Business API (مدفوع ويحتاج خادم خلفي) — يمكن إضافته لاحقًا كتطوير منفصل.

## لوحة التحكم — ما تتحكم فيه فعليًا

من `admin.html` (كلمة المرور الافتراضية: `lucine2026`، يمكن تغييرها من اللوحة، ولم يعد رابطها ظاهرًا في الموقع — يُفتح فقط بكتابة `admin.html` مباشرة بعد رابط موقعكم):

- رقم الواتساب المستقبل للطلبات، ورمز الدولة الافتراضي في خانة الهاتف (+213 حاليًا).
- روابط انستغرام وفيسبوك.
- **الهوية البصرية والخطوط**: اللون الأساسي ولون النصوص، خط العناوين وخط النصوص (لاتيني) والخط العربي، واللوقو الكامل ولوقو الأيقونة (برفع صورة جديدة أو الاستعادة للّوقو الأصلي).
- كل نصوص الصفحة الرئيسية (العنوان، من نحن، المشكلة والحل) لكل لغة.
- قوائم الخدمات (إضافة/حذف/تعديل) لكل لغة.
- **الفئات المستهدفة والتخصصات الدقيقة**: محرر واحد تكتب فيه الاسم بالعربية والفرنسية والإنجليزية معًا في نفس الوقت (بدل التنقل بين تبويبات اللغات)، لكل فئة ولكل تخصص دقيق تابع لها. هكذا حين يفتح الطبيب الموقع بأي لغة ويختار مثلاً "الأطباء بمختلف التخصصات"، تظهر له قائمة التخصصات جاهزة ومترجمة تلقائيًا بلغته.

## نموذج الأطباء — التفاصيل الجديدة

- **خانة الولاية**: قائمة منسدلة (Dropdown) تحتوي كل ولايات الجزائر الـ58 مرتبة برقمها الرسمي.
- **خانة الهاتف**: رمز الدولة (+213 افتراضيًا، قابل للتعديل من اللوحة) مكتوب مسبقًا في خانة صغيرة، والطبيب يكتب رقمه مباشرة في الخانة المجاورة.
- **خانة التخصص الدقيق**: تظهر تلقائيًا بعد اختيار "الأطباء بمختلف التخصصات" (أو أي فئة أخرى أضفتم لها تخصصات من اللوحة)، وتختفي إن لم تكن هناك تخصصات معرّفة لتلك الفئة.

⚠️ **ملاحظة مهمة جدًا حول عمل لوحة التحكم على موقع ستاتيكي:**
عند الضغط على "حفظ" في اللوحة، تُحفظ التعديلات في متصفحكم فقط (Local Storage) — أي أنها لن تظهر لباقي الزوار تلقائيًا، لأن GitHub Pages يستضيف ملفات ثابتة ولا توجد قاعدة بيانات مركزية. لجعل أي تعديل **دائمًا وظاهرًا للجميع**:

1. عدّلوا المحتوى من لوحة التحكم كما تريدون.
2. اذهبوا لتبويب "النشر على GitHub" واضغطوا "تجهيز ملف config.js للتصدير" ثم "تحميل config.js".
3. استبدلوا الملف `js/config.js` في مجلد مشروعكم بالملف الذي حمّلتموه.
4. ارفعوا (push) التعديل إلى GitHub كما هو موضح أدناه — سيظهر فورًا لكل الزوار.

ملاحظة: إذا رفعتم لوقو جديدًا من تبويب "الهوية البصرية"، فإن صورة اللوقو تُحفظ داخل `config.js` نفسه (بصيغة Base64)، لذلك حجم الملف المصدَّر سيكبر قليلاً — وهذا طبيعي ولا يؤثر على عمل الموقع.

كلمة مرور اللوحة نفسها أيضًا: تعديلها من اللوحة يُحفظ محليًا فقط، فإذا أردتم تغييرها بشكل دائم يجب تصدير `config.js` ورفعه أيضًا.

## خطوات الرفع على GitHub ونشر الموقع (GitHub Pages)

### 1. إنشاء المستودع (Repository)
- ادخلوا إلى [github.com](https://github.com) وأنشئوا حسابًا إذا لم يكن لديكم واحد.
- اضغطوا **New repository**، أعطوه اسمًا مثل `lucine-studio-site`، اختاروا **Public**، ثم **Create repository**.

### 2. رفع الملفات
أسهل طريقة بدون استخدام سطر الأوامر:
- داخل المستودع الفارغ، اضغطوا **uploading an existing file**.
- اسحبوا كل محتويات مجلد `lucine-site` (وليس المجلد نفسه، بل ما بداخله) إلى الصفحة.
- اكتبوا رسالة مثل "أول نسخة من الموقع" واضغطوا **Commit changes**.

أو عبر سطر الأوامر (Git):
```bash
cd lucine-site
git init
git add .
git commit -m "أول نسخة من موقع Lucine Studio"
git branch -M main
git remote add origin https://github.com/USERNAME/lucine-studio-site.git
git push -u origin main
```
(استبدلوا `USERNAME` باسم حسابكم على GitHub)

### 3. تفعيل GitHub Pages
- داخل المستودع، اذهبوا إلى **Settings** ثم **Pages** من القائمة الجانبية.
- تحت **Build and deployment** → **Source**، اختاروا **Deploy from a branch**.
- اختاروا **Branch: main** و **Folder: / (root)**، ثم **Save**.
- انتظروا دقيقة أو دقيقتين، وسيظهر لكم رابط الموقع بالشكل:
  `https://USERNAME.github.io/lucine-studio-site/`

### 4. بعد النشر
- افتحوا `.../admin.html` من نفس الرابط لضبط رقم الواتساب وباقي الإعدادات لأول مرة، ثم اتبعوا خطوات التصدير أعلاه لجعل الإعدادات دائمة.
- في أي تعديل مستقبلي: عدّلوا الملفات محليًا أو عبر GitHub مباشرة (زر القلم ✏️ على كل ملف في GitHub)، وأي حفظ (commit) يُحدّث الموقع المباشر تلقائيًا خلال دقيقة تقريبًا.

### ربط دومين خاص (اختياري)
إذا كان لديكم اسم نطاق خاص (مثل lucinestudio.com)، من نفس صفحة **Settings → Pages** يوجد حقل **Custom domain** — أضيفوا الدومين هناك، وأضيفوا سجل CNAME في إعدادات مزوّد النطاق يشير إلى `USERNAME.github.io`.
